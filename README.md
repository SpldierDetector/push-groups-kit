Push Groups Kit

Android notification grouping for Expo and React Native applications.

Work in progress: This project is in early development and is not ready for production use.

Overview

Push Groups Kit is an open-source native module focused on providing flexible Android notification grouping for Expo and React Native apps.

The goal is to make conversation-style notifications and notification group management easier to implement.

Planned Features

Group notifications by a custom group ID.

Display expandable notification groups.

Manage individual notifications and group summaries.

Dismiss notifications selectively.

Support configurable notification behavior.

Explore custom notification sounds and channels.

Current Status

The initial Expo module structure has been created.

The first development target is Android with Expo SDK 57.

The notification grouping API has not been implemented yet.
